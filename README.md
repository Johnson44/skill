# skill

Reusable Codex skills, starting with an HRBP resume and interview assistant.

## Included skills

- `hrbp-resume-interview/`: resume revision and interview preparation for AI product roles.
  - `SKILL.md`: core instructions
  - `references/`: business, role, research, and output guidance
  - `agents/openai.yaml`: skill metadata

## Adding future skills

Create one top-level directory per skill. Each skill should include its own `SKILL.md` and keep supporting references or agent metadata inside that directory. Do not upload private resumes, contact details, temporary files, or generated artifacts unless they have been sanitized.
